## 📂 ساختار گزارش‌ها و فایل‌های استخراج‌شده نماد بانیان

مطابق با دستورات استخراج، کلیه فایل‌های گزارش‌های کدال (اکسل و پی‌دی‌اف)، اخبار و داده‌های تابلوی معاملات دانلود و سازمان‌دهی شدند:

`	ext
سهام/بانیان/
├── README.md                      # همین فایل (داشبورد و شناسنامه سهم)
├── links.txt                      # فایل پیوندها و دستورالعمل‌های استخراج
├── final_recommendation.md        # گزارش پیشنهاد معاملاتی و مدیریت ریسک جامع
├── fundamental_report.md          # گزارش فوق‌تفصیلی بنیادی و ارزش‌گذاری
├── technical_report.md            # گزارش فوق‌تفصیلی تکنیکال، ایچیموکو و تابلوخوانی
├── strategy_recommendation.json   # فایل ساختاریافته داده‌های استراتژی
├── codal_reports/                 # پوشه اسناد و فایل‌های دانلودشده کدال (۵۰ فایل)
│   ├── 9_صورت‌های_مالی_سال_مالی_منتهی_به_۱۴۰.xlsx
│   ├── 9_صورت‌های_مالی_سال_مالی_منتهی_به_۱۴۰.pdf
│   ├── 3_اطلاعات_و_صورت‌های_مالی_میاندوره‌ای.xlsx
│   ├── 1_گزارش_فعالیت_ماهانه_دوره_۱_ماهه_منت.xlsx
│   ├── letters_index.json         # فهرست کامل اطلاعیه‌های کدال
│   └── codal_summaries.md         # خلاصه تحلیلی صورت‌های مالی و تولید/فروش
├── news/                          # پوشه اخبار و رویدادهای بازار
│   ├── news_archive.json          # آرشیو ساختاریافته کلیه اخبار
│   └── news_summary.md            # خلاصه اخبار و سنتیمنت بازار
├── market_data/                   # پوشه دیتای بازار و تابلوی معاملات TSETMC
│   ├── trade_history.csv          # تاریخچه کامل قیمت‌ها و حجم‌های معاملاتی
│   └── orderbook_tape.json        # اطلاعات سرانه حقیقی/حقوقی و قدرت خریدار
└── charts/                        # نمودارهای تصویری با تایپوگرافی فارسی
    ├── candlestick_overview.png   # نمودار شمعی، میانگین‌ها و باندهای بولینگر
    ├── indicators_momentum.png    # اسیلاتورهای RSI و MACD با تفکیک مناطق بحرانی
    └── tape_reading_money_flow.png # نوار قدرت خریداران حقیقی در برابر فروشندگان
`
