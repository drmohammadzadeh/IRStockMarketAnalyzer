# 📈 تحلیلگر هوشمند و جامع بازار سرمایه ایران (IRStockMarketAnalyzer)

> **یک موتور تحلیلی خودکار، مبتنی بر پایتون برای تحلیل تکنیکال، بنیادی، تابلوخوانی و صدور پیشنهادهای معاملاتی چندزمانی در بورس و فرابورس ایران (TSE / Farabourse).**

---

## 📖 معرفی پروژه

پروژه **IRStockMarketAnalyzer** با هدف خودکارسازی فرآیند تحلیل سهام در بازار سرمایه ایران طراحی و توسعه یافته است. این سیستم به گونه‌ای عمل می‌کند که در پوشه `سهام/` به ازای هر زیرپوشه (که نام آن نماد سهم است، مانند `زهلال` یا `فسازان`)، تمامی اطلاعات زنده، تاریخی و رسمی سهم را استخراج، پالایش و تحلیل کرده و در نهایت **۳ گزارش تحلیلی کامل با فرمت Markdown** به همراه **نمودارهای استاندارد با تایپوگرافی فارسی** در همان پوشه ایجاد می‌کند.

---

## ✨ ویژگی‌های کلیدی

### ۱. استخراج داده و تابلوخوانی هوشمند (TSETMC Engine)
- دریافت خودکار تاریخچه کندل‌های تعدیل‌شده قیمتی (شامل باز، بسته، بالاترین، پایین‌ترین، حجم و ارزش معاملات).
- خواندن اطلاعات حقیقی/حقوقی تابلو در آخرین روز معاملاتی:
  * محاسبه سرانه خرید و فروش حقیقی (میلیون تومان به ازای هر کد).
  * محاسبه نسبت قدرت خریدار به فروشنده حقیقی ($Power = \frac{BuyCapita}{SellCapita}$).
  * شناسایی حجم‌های مشکوک و تخمین جریان ورود/خروج نقدینگی و پول هوشمند.

### ۲. استخراج صورت‌های مالی و اطلاعات کدال (Codal Engine)
- اتصال مستقیم به سامانه کدال (Codal) و خواندن فایل `links.txt` موجود در پوشه سهم.
- استخراج و دسته‌بندی خودکار اطلاعیه‌ها:
  * صورت‌های مالی میان‌دوره‌ای (۳، ۶، ۹ و ۱۲ ماهه).
  * گزارش‌های فعالیت ماهانه تولید و فروش.
  * افشای اطلاعات بااهمیت (گروه الف و ب).
  * تصمیمات مجامع عمومی سالیانه و سود مصوب تقسیمی (DPS).

### ۳. لایه صحت‌سنجی و اعتبارسنجی داده‌ها (Data Integrity & Validator)
- بررسی عدم تناقض در داده‌های قیمت (بررسی نامعتبر نبودن سقف/کف و مثبت بودن قیمت‌ها).
- هشدار در صورت توقف طولانی‌مدت نماد یا حجم معاملات صفر.
- اعتبارسنجی ارقام مالی و تاریخی قبل از ورود به موتورهای تحلیلی.

### ۴. موتور تحلیل تکنیکال و رسم نمودار (Technical & Charting Engine)
- محاسبه میانگین‌های متحرک نمایی (EMA 20, 50, 100, 200) و بررسی شیب روند.
- محاسبه اسیلاتور RSI (14 روزه) و سطوح اشباع خرید/فروش.
- محاسبه اندیکاتور MACD (12, 26, 9) به همراه خط سیگنال و میله‌های هیستوگرام.
- سیستم معاملاتی ایچیموکو (Tenkan-sen, Kijun-sen, Senkou Span A/B, Chikou Span).
- باندهای بولینگر (20, 2) برای تشخیص فشردگی و شکست باند.
- محاسبه اندیکاتور ATR (14) برای تعیین دقیق حد ضرر متناسب با نوسان سهم.
- استخراج پیوت‌های قیمتی و ترازهای فیبوناچی اصلاحی (۲۳.۶٪، ۳۸.۲٪، ۵۰٪، ۶۱.۸٪، ۷۸.۶٪).
- **رسم ۳ نمودار باکیفیت بالا با فونت و راست‌چین فارسی** در پوشه `charts/`:
  1. `candlestick_overview.png`: نمودار قیمت، میانگین‌ها، باند بولینگر و حجم معاملات.
  2. `indicators_momentum.png`: اسیلاتورهای RSI و MACD.
  3. `tape_reading_money_flow.png`: نمودار تجمعی جریان نقدینگی.

### ۵. موتور تحلیل بنیادی و ارزش‌گذاری (Fundamental Engine)
- ارزیابی نسبت‌های کلیدی ارزش‌گذاری: نسبت $P/E_{ttm}$، نسبت $P/S$، نسبت $P/B$.
- محاسبه بازده نقدی سود تقسیمی مجمع (Dividend Yield).
- محاسبه حاشیه‌های سودآوری (حاشیه سود ناخالص، عملیاتی و خالص).
- تحلیل روند مبالغ و نرخ فروش گزارش‌های ماهانه و محاسبه نرخ رشد ماهانه (MoM).
- اختصاص نمره ارزیابی بنیادی از ۱ تا ۱۰.

### ۶. موتور استراتژی و پیشنهاد معاملاتی چندزمانی (Recommendation Matrix)
- صدور سیگنال شفاف: `خرید قوی (Strong Buy)`، `خرید پله‌ای (Accumulate)`، `نگهداری (Hold)`، یا `سیو سود / خروج (Sell / Exit)`.
- محاسبه دقیق پارامترهای معامله:
  * **محدوده خرید بهینه (Entry Zone)**
  * **حد سود اول (Target 1)** بر اساس مقاومت نزدیک
  * **حد سود دوم (Target 2)** بر اساس سقف ماژور و فیبوناچی
  * **حد ضرر قطعی (Stop Loss)** بر اساس ATR و کف حمایتی
  * **نسبت ریسک به ریوارد ($R/R$)**
- تفکیک راهبرد معاملاتی در **۳ افق زمانی**:
  * **کوتاه‌مدت (۱ تا ۴ هفته):** نوسان‌گیری با تابلوخوانی و پول هوشمند.
  * **میان‌مدت (۱ تا ۳ ماه):** بهره‌گیری از شکست الگوها و گزارش‌های ماهانه کدال.
  * **بلندمدت (۶ تا ۱۲ ماه):** با دید ارزش ذاتی، P/E تحلیلی و سود مجمع.
- تعیین شروط صریح ابطال سناریوی تحلیل.

### ۷. پایش خودکار دایرکتوری (Directory Watcher)
- مانیتورینگ دائمی پوشه `سهام/`؛ به محض ساخته شدن هر زیرپوشه جدید توسط کاربر، فرآیند تحلیل فوراً و بدون نیاز به دخالت اجرا شده و گزارش‌ها تولید می‌گردد.

## 🚀 نصب و راه‌اندازی سریع

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/drmohammadzadeh/IRStockMarketAnalyzer.git
cd IRStockMarketAnalyzer
```

### ۲. ایجاد محیط مجازی و نصب وابستگی‌ها
```bash
python -m venv .venv

# در ویندوز:
.venv\Scripts\activate

# در لینوکس / مک:
source .venv/bin/activate

# نصب پکیج‌ها:
pip install -r requirements.txt
```

## 💻 راهنمای استفاده (CLI)

### ۱. تحلیل یک نماد مشخص
برای تحلیل هر سهم، کافی است نام نماد را جلوی دستور وارد کنید (در صورتی که پوشه آن وجود نداشته باشد به طور خودکار ساخته می‌شود):
```bash
python main.py زهلال
```

### ۲. تحلیل تمامی نمادهای موجود در پوشه `سهام/`
برای پردازش دسته‌ای (Batch) تمامی نمادهایی که پوشه آن‌ها در `سهام/` قرار دارد:
```bash
python main.py --all
```

### ۳. اجرای پایشگر خودکار در پس‌زمینه (Watch Mode)
در این حالت اسکریپت در حال اجرا باقی می‌ماند و به محض اینکه شما یک پوشه جدید (مثلاً `سهام/فولاد/`) ایجاد کنید، بلافاصله آن را شناسایی و تحلیل می‌کند:
```bash
python main.py --watch
```

## 📊 نمونه گزارش‌های تولیدشده (مثال: نماد زهلال)

در پوشه هر نماد، سه فایل جامع تولید می‌شود:

### ۱. فایل `final_recommendation.md`
شامل جدول شفاف پارامترهای ورود، حد ضرر و اهداف قیمتی:
```markdown
| پارامتر معامله | مقدار پیشنهادی | توضیحات |
| :--- | :--- | :--- |
| **محدوده خرید بهینه** | 46,579 تا 48,481 ریال | بازه قیمتی مجاز برای ورود پله‌ای |
| **حد سود اول (Target 1)** | 50,890 ریال | مقاومت اول (+7.1% بازدهی) |
| **حد سود دوم (Target 2)** | 55,979 ریال | سقف ماژور (+17.8% بازدهی) |
| **حد ضرر قطعی (Stop Loss)** | 46,254 ریال | شکست کف حمایتی (-2.7% ریسک) |
| **نسبت ریسک به ریوارد (R/R)** | 2.63 | بسیار جذاب (R/R >= 2) |
```

### ۲. فایل `fundamental_report.md`
شامل نمره بنیادی، بررسی صورت‌های مالی، ارزیابی ضرایب P/E و P/S و کیفیت سودآوری شرکت.

### ۳. فایل `technical_report.md`
شامل وضعیت RSI، میانگین‌های متحرک نمایی، حمایت‌ها و مقاومت‌های استاتیک/داینامیک، تحلیل سرانه خریدار و فروشنده، و لینک نمودارهای گرافیکی.
